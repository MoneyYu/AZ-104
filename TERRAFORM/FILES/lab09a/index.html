Azure Files 掛載成功

這個檔案來自 Azure Files 共用

您現在看到的這個網頁，實際上並未直接部署在 App Service 的本機 site\wwwroot 目錄中，而是儲存在 Azure Files 共用（File Share） 內，再透過 App Service 的「儲存體掛接（Storage Mount）」功能， 掛載到 App Service 的 /mounts/content 路徑。

  • 儲存體帳戶：azurerm_storage_account
  • 檔案共用：azurerm_storage_share（共用名稱 content）
  • 掛載設定：Web App 的 storage_account 區塊，型別為 AzureFiles

這示範了如何讓 App Service 透過共用金鑰驗證存取 Azure Files，將內容與應用程式的程式碼儲存體分離管理。
